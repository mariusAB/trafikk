# Lillian tar lappen

En mobilvennlig enkeltside på norsk. Ren HTML, CSS og JavaScript, uten byggetrinn eller avhengigheter. Google Fonts er valgfritt; siden bruker lokale reservefonter hvis forespørselen feiler.

## Lokal forhåndsvisning

Kjør `python -m http.server 3000` i denne mappen, og åpne http://localhost:3000.

## Vercel

Importer dette repoet i Vercel. Velg **Other** som Framework Preset, la Build Command være tom, og bruk **.** som Output Directory. Ingen miljøvariabler er nødvendige. Alternativt: kjør `vercel` fra prosjektmappen med Vercel CLI.

## Regnestykket

WHO oppgir 20–50 millioner ikke-dødelig trafikkskadde globalt per år. Siden bruker nedre anslag: 20 000 000 × 0,0005 = 10 000 per år. Måned, dag og time er avrundet fra et år på 365 dager. 2 000 prikker med én markert viser andelen 0,05 %.

Dette er et humoristisk regneeksempel på trafikkskadde, ikke en prognose eller et globalt antall trafikkulykker. Skadde personer og ulykker er forskjellige størrelser.

Kilde: https://www.who.int/news-room/fact-sheets/detail/road-traffic-injuries/

Førerkortdatoen er satt til 27. november 2026 i `index.html`.
